## Featured Projects

### 1. Multisite Satellite Analysis of Data-Centre Developments in Malaysia

**Tools:** Google Earth Engine, Landsat, Sentinel imagery, Python, R, GIS

A multisite research project investigating land-surface temperature, vegetation, and built-up surface patterns around data-centre developments in Malaysia.

The analysis includes satellite image processing, cloud masking, seasonal composites, distance-based analysis, pre- and post-development comparisons, and Before–After–Control–Impact (BACI) analysis.

*Project documentation and selected figures will be added as they are prepared for sharing.*

### 2. Sustainable and Climate-Resilient Data-Centre Siting in Germany

**Tools:** GIS, spatial analysis, multi-criteria decision analysis

My MSc thesis at the University of Bonn investigates a GIS-based approach to identifying suitable locations for sustainable and climate-resilient data-centre development in Germany.

The research involves spatial criteria selection, geospatial data preparation, standardisation, expert-informed weighting using the Best–Worst Method (BWM), suitability modelling, and sensitivity analysis.

*This project is in progress.*

### 3. Apartment Location Suitability Analysis — Bonn, Germany

**Tools:** QGIS, spatial analysis

A GIS project applying spatial analysis to assess apartment location suitability using selected geographic criteria.

### 4. Flood Risk Assessment and Visualisation — Manila, Philippines

**Tools:** GIS, Python, geospatial visualisation

A geospatial project exploring flood-risk patterns through spatial analysis and visualisation.
